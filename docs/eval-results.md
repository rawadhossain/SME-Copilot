# Evaluation on generated crises

_Generated by `bun run eval`. Do not edit by hand. Seed 20261018, 60 generated companies, world date 2026-10-15._

This measures the SYSTEM: the search that builds plans, the permission gate, the executor and the independent verifier. It does not measure a language model: the planner is the deterministic planner and no model is called. The companies are synthetic copies of one demo business with generated crises, and every counterparty is a simulator with a fixed personality.

## Setup

- Seed 20261018; 60 cases; each case is a fresh throwaway copy of the demo business flagged as a test business. The generator (`scripts/eval/generate.ts`) uses a seeded mulberry32 stream per case: no Math.random, no clock.
- The ranges below were fixed before the first run and are not tuned to improve any rate.
- Each case: perturb the copy, confirm the sample order (this runs the shortage check), plan with the deterministic planner, take the top-ranked plan that can run, sign it (owner and second approver, dev keys), execute it against the simulated counterparties, re-plan with the product's own limit of 2 rounds if a counterparty pushes back, then verify independently.
- Limit violations and floor breaches are recomputed from the sandbox tables and the stored mandate, not taken from the engine's promise.
